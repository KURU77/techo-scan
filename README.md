# 手帳スキャン

紙の手帳に書き込んだ予定を写真から読み取って、`.ics` としてスマホのカレンダーに **追加** するアプリです。

**→ https://kuru77.github.io/techo-scan/**

依存ライブラリなしの `index.html` 1枚。予定データはブラウザの localStorage にだけ保存されます。iPhone の Safari から「ホーム画面に追加」すると PWA として使えます。

## 何をするものか

週間バーチカルの手帳を撮ると、こうなります。

```
2026-09-11 (木)
  10:00-11:30  定例会議 @第2会議室
  19:00-20:00  歯医者

2026-09-12 (金)
  終日         出張（大阪）
```

これをそのまま `.ics` にして共有シートに流し込むので、**FirstSeed カレンダー**や iOS 標準カレンダーに取り込めます。**Google カレンダー**にも、iOS 経由・API で直接・1 件ずつの 3 通りで入れられます。

## FirstSeed カレンダーへの追加について

`.ics` の取り込みは **追加** です。もともと入っていた予定が消えたり、置き換わったりすることはありません。

1. 書き出しタブの **共有して FirstSeed に送る** を押す
2. 共有シートから **FirstSeed カレンダー** を選ぶ
   - 出てこないときは **ファイルに保存** → ファイル App でタップ → 「FirstSeed カレンダーで開く」
3. FirstSeed 側で取り込み先のカレンダーを選んで確定

同じ予定を二度送ってしまわないよう、一度書き出した予定には「書き出し済み」の印が付きます。書き出しタブの **書き出し済みの予定は除く** をオンにしておくと、次からは差分だけが出ます。

## Google カレンダーへの追加について

**iPhone の Google カレンダーには、App にもブラウザ版にもインポート機能がありません**（`.ics` も CSV も読み込む口がない。PC のブラウザ版だけにあります）。そのため 3 通り用意しています。どれも追加だけで、既存の予定には触りません。

| 方法 | 手間 | 向き |
|---|---|---|
| **A. iOS 経由で一括** | iOS に Google アカウントを追加してあれば手間ゼロ | いちばん簡単。まずこれを試す |
| **B. 直接まとめて登録** | 初回だけ Google Cloud でクライアント ID を作る（10 分・無料） | 毎週まとめて入れる人 |
| **C. 1 件ずつ** | なし | 数件だけのとき |

### A. iOS 経由で一括（おすすめ）

iPhone の **設定 → カレンダー → アカウント** に Google アカウントを追加してあれば、Google のカレンダーは iOS のカレンダーとして見えています。

1. 書き出しタブの **共有して FirstSeed に送る**（または「.ics を保存」→ ファイル App で開く）
2. iOS の「カレンダー」か FirstSeed カレンダーで取り込むとき、**取り込み先に Google のカレンダーを選ぶ**

これだけで Google カレンダーに一括で入り、iPhone の Google カレンダー App にも同期されます。

### B. 直接まとめて登録（Calendar API）

Google アカウントでログインして、選択した予定を Google カレンダーに直接 `insert` します。このアプリはサーバーを持たないので、**自分用の OAuth クライアント ID** を一度だけ作ってもらいます。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作る（名前は何でも）
2. **API とサービス → ライブラリ** で「Google Calendar API」を有効にする
3. **API とサービス → OAuth 同意画面** で外部・アプリ名を適当に入れて作成し、**テストユーザー**に自分の Google アカウントを追加する
4. **API とサービス → 認証情報 → 認証情報を作成 → OAuth クライアント ID**
   - 種類: **ウェブ アプリケーション**
   - 承認済みの JavaScript 生成元: `https://kuru77.github.io`
   - 承認済みのリダイレクト URI: `https://kuru77.github.io/techo-scan/`
5. できた **クライアント ID**（`….apps.googleusercontent.com`）を、このアプリの設定に貼る

あとは書き出しタブの **Google でログインして追加する** → 登録先のカレンダーを選ぶ → **N 件をまとめて登録**。ログインは 1 時間ほど有効です。Google の画面で「このアプリは Google で確認されていません」と出たら、**詳細 → （アプリ名）に移動** で進めます（自分で作ったクライアントなので問題ありません）。

- 求める権限は「予定の作成・編集」と「カレンダー一覧の閲覧」だけ。既存の予定は読みも消しもしません
- トークンはこの端末の localStorage に 1 時間だけ置き、送信先は `googleapis.com` だけです
- 一度登録した予定には「書き出し済み」の印が付くので、二重登録は「書き出し済みの予定は除く」で避けられます

### C. 1 件ずつ

書き出しタブの一覧で **開く** を押すと、内容が埋まった Google カレンダーの登録画面が開きます。確認して保存するだけ。設定は要りません。

## できること

| | |
|---|---|
| 読み取り | 手帳の写真（最大8枚）から日付・開始/終了時刻・内容・場所を抽出。Google Gemini（無料枠あり）か Anthropic Claude を選べる |
| 手がかり | 「このページはいつ頃か」を渡して、年が書かれていないページの年を推定 |
| 手直し | 一覧をタップして編集。自信の低い読み取りには <kbd>要確認</kbd> が付く |
| 手入力 | 予定をゼロから足すこともできる |
| テキスト取り込み | `9/11 10:00-11:30 会議 @第2会議室` のような文章を貼って予定にする（APIキー不要） |
| 書き出し | `.ics` を共有／保存、Google カレンダーに直接まとめて登録（要クライアント ID）／1 件ずつ登録画面を開く、予定をテキストでコピー |
| 二重登録よけ | 書き出した予定に印を付け、次回以降は除外できる |
| 通知 | `.ics` にアラーム（10分前〜前日）を付けられる |
| オフライン | 画面はオフラインでも開ける（読み取りだけ通信が必要） |

## API キーが必要です

手書き文字の読み取りは、このアプリ単体ではできません。画像は **Google Gemini** か **Anthropic Claude** に送って解析します。GitHub Pages 上の静的ページなので鍵を預かるサーバーがなく、**利用者自身の API キー**を使う作りにしています。設定で切り替えられます。

### Google Gemini（無料で始めたい人向け・既定）

- 発行: [Google AI Studio](https://aistudio.google.com/apikey)。Google アカウントがあればすぐ作れます
- 費用: 無料枠があり、手帳を数ページ読む程度なら 0 円。1 分あたりの回数制限に当たったら少し待つか Flash-Lite に切り替え
- 注意: **無料枠では、送った内容が Google のサービス改善（学習）に使われることがあります。** 手帳に人の名前や私的な予定が多い場合は、有料プランにするか Claude を使ってください
- 送信先: `generativelanguage.googleapis.com` のみ
- モデルは既定で Gemini 3.8 Flash。設定の「このキーで使えるモデルを取得」を押すと、そのキーで呼べるモデル一覧に置き換わります

### Anthropic Claude（手書きの読み取り精度を優先したい人向け）

- 発行: [console.anthropic.com](https://console.anthropic.com/settings/keys)
- 費用: 従量課金。Opus 5 で手帳 1 ページあたりおよそ 2〜6 円（画像 1 枚 ≒ 1,500 入力トークン前後）
- 送った内容は学習に使われません
- 送信先: `api.anthropic.com` のみ。ブラウザから直接呼びます

| モデル | 向き |
|---|---|
| Claude Opus 5（既定） | 手書き。いちばん読める |
| Claude Sonnet 5 | 読みやすい手書き・混在ページ |
| Claude Haiku 4.5 | 活字中心のページ。最安 |

### 共通

- キーの保存先はこの端末の localStorage だけ（設定で「キーをこの端末に保存する」を外せば一時保存）
- **キーを使いたくない場合**は、読み取りタブ下部の「テキストから取り込む」に予定を書き並べれば、`.ics` の生成だけを使えます

## 読み取りの精度を上げるコツ

- 見開きは **1ページずつ** 撮る（2ページ同時より安定します）
- ページ全体が入るように、**真上から**、影が落ちない明るさで
- 年をまたぐページは、先に「このページはいつ頃か」を合わせておく
- レイアウトに癖がある手帳は、補足欄に「左が週間バーチカル、赤字は仕事」などと書いておくと効きます

手書きの読み取りは必ずどこかを間違えます。**予定タブでの手直しが前提**の道具だと思ってください。取り消し線で消した予定は読み飛ばします。

## データの扱い

- 読み取った予定・設定・API キー・Google のログイントークン（1 時間） → この端末の localStorage
- 写真 → メモリ上のみ。保存も送信もしません（解析時に Gemini / Anthropic へ送る場合を除く）
- このサイト自身はサーバーを持たず、アクセス解析も入れていません

## 開発

```bash
node icons.mjs   # アイコンを作り直す
```

ビルドはありません。`index.html` を直接編集します。ローカルで見るときは、Service Worker が要るので `file://` ではなく簡易サーバー経由で開いてください。

```bash
npx serve .
```
